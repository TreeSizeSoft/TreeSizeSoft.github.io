Getting started

Use TreeSize Free to inspect a drive or a specific folder and see what is using its storage.

  • 01Download and extract the ZIP, then run the original installer inside.
  • 02Start TreeSize Free and select a drive or folder to scan.
  • 03Sort by size, explore the treemap, and create a PDF report if needed.
